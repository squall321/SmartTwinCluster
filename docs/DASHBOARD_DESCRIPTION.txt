1. Auth Portal Backend (Port 4430) — SSO/JWT 통합 인증 서버
--------------------------------------------------------------------------------

- SAML 2.0 / OIDC / Mock 인증을 하나의 엔드포인트로 통합 지원하는 중앙 인증 서버
- Flask 기반, Gunicorn 프로덕션 서빙, Redis 세션 관리

[인증 흐름]
- SAML_LOGIN
  - SAML IdP로 리다이렉트, ACS(Assertion Consumer Service) 엔드포인트에서 Assertion 수신
  - python3-saml 라이브러리 기반 SP 구현
  - 속성 매핑: uid → username, email, groups, displayName, department
- OIDC_LOGIN
  - Authorization Code Flow, Authlib 기반 토큰 교환
  - IdP Issuer URL, Client ID/Secret 설정
  - Scope: openid, profile, email, groups
- MOCK_LOGIN
  - SSO 비활성화 시 테스트용 로컬 로그인
  - YAML에서 test_users 로드

[JWT 토큰]
- 인증 성공 시 JWT 발급 (PyJWT, HS256)
- 만료: 8시간 (설정 가능)
- Payload: username, email, groups, permissions, exp
- 모든 백엔드 서비스가 이 토큰으로 사용자 인증

[API 엔드포인트]
- GET  /health              — 헬스체크
- GET  /auth/info            — 인증 설정 정보 (SSO 타입, 활성화 여부)
- GET  /auth/saml/login      — SAML SSO 시작
- POST /auth/saml/acs        — SAML Assertion 수신
- GET  /auth/oidc/login      — OIDC 인증 시작
- GET  /auth/oidc/callback   — OIDC 토큰 교환
- POST /auth/test/login      — Mock 로그인 (개발용)


2. Auth Portal Frontend (Port 4431) — 인증 UI 및 서비스 포탈
--------------------------------------------------------------------------------

- React 19 + Vite + TypeScript 기반 로그인 UI
- SAML/OIDC 리다이렉트 처리 및 JWT 콜백 수신

[페이지 구성]

- CallbackPage    — OAuth/SAML 콜백 처리, JWT 저장
- ServiceMenuPage — 로그인 후 서비스 선택 (Smart Twin Flow / Extreme 등)
- VNCPage         — VNC 서비스 네비게이션


3. SAML Identity Provider (Port 7000) — 테스트용 SAML IdP
--------------------------------------------------------------------------------

- Node.js 기반 독립 SAML 2.0 Identity Provider
- SSO 비활성화 시(sso.enabled: false) 개발/테스트용으로 동작
- YAML에서 test_users 정보 로드하여 사용자 DB 자동 생성
- SAML Metadata 엔드포인트 제공
- HTTPS 인증서(certs/) 내장
- 지원 속성: email, userName, firstName, lastName, displayName, groups


4. Dashboard Backend (Port 5010) — HPC 클러스터 통합 관리 API
--------------------------------------------------------------------------------

- Flask + SocketIO 기반 메인 REST API 서버
- Slurm 클러스터 실시간 연동 (Production Mode) 또는 Mock 모드 지원
- 22개 Blueprint 모듈로 기능 분리

[Slurm 클러스터 관리]
- CLUSTER_STATUS
  - sinfo/scontrol 명령 래핑, 노드 상태/리소스 실시간 조회
  - CPU/Memory/GPU 할당률 계산
  - Production/Mock 모드 자동 전환
- JOB_MANAGEMENT
  - squeue/sacct 기반 잡 목록 조회 (Active/Completed/Failed)
  - 잡 제출(sbatch), 취소(scancel), 홀드/릴리즈
  - 잡 로그 실시간 스트리밍 (job_logs 블루프린트)
- NODE_MANAGEMENT
  - 노드 드레인/재개/재부팅 명령
  - 노드 그룹 관리 (YAML 기반)
  - 리소스 그룹 드래그앤드롭 구성
- JOB_TEMPLATES
  - 작업 템플릿 CRUD (v2, SQLite 영구 저장)
  - 카테고리별 분류 (Official/Community/Private)
  - YAML 업로드, 핫 리로드, Scan & Sync

[스토리지 관리]
- DATA_MANAGEMENT
  - /data (Shared Storage), /scratch (Local Scratch) 탭 전환
  - 디렉토리 탐색, 파일 미리보기 (FilePreview)
  - 멀티노드 파일 전송 (MultiNodeTransfer)
- FILE_UPLOAD
  - 대용량 파일 업로드 (최대 50GB, 드래그앤드롭)
  - 업로드 이력 조회
  - Phase 3 통합 구조
- DISK_ALERTS
  - 디스크 사용량 실시간 모니터링
  - 임계값 초과 시 경고 알림

[LS-DYNA 통합]
- LSDYNA_SUBMIT
  - LS-DYNA 전용 잡 제출 (Apptainer SIF 이미지 선택)
  - 파티션/QoS/리소스 설정
  - 템플릿 기반 배치 제출

[원격 접속]
- VNC_SESSIONS
  - Slurm 잡으로 VNC 세션 생성 (Apptainer 컨테이너)
  - 파티션 선택 (viz/gpu/normal)
  - SSH 터널 자동 생성 → noVNC WebSocket 프록시
  - GPU 가속 지원 (--nv 플래그)
  - Sandbox 기반 영구 사용자 환경
- SSH_TERMINAL
  - 브라우저 내 SSH 웹 터미널
  - Paramiko 기반 SSH 게이트웨이

[모니터링]
- PROMETHEUS_METRICS
  - Prometheus 메트릭 수집/노출 (/metrics)
  - PromQL 쿼리 프록시
  - 실시간 CPU/Memory/GPU 사용률
- HEALTH_CHECK
  - Backend API, Database, Redis, Slurm 서비스 상태 점검
  - Auto-refresh (30초)

[컨테이너 관리]
- APPTAINER_CATALOG
  - 배포된 SIF 이미지 목록 조회
  - 이미지 메타데이터 (크기, 버전, 타입)
  - 이미지 선택 → 잡 제출 연동

[미들웨어]
- jwt_middleware.py — JWT 토큰 검증, SSO 설정 연동
  - @jwt_required — 인증 필수 엔드포인트
  - @optional_jwt — 인증 선택 엔드포인트
  - @permission_required('dashboard') — 권한 기반 접근 제어
- rate_limiter.py — 요청 속도 제한

[API 엔드포인트 — 주요 50개 이상]
- GET  /api/health                    — 헬스체크
- GET  /api/metrics/realtime          — 실시간 클러스터 메트릭
- GET  /api/slurm/jobs                — 잡 목록
- POST /api/slurm/jobs                — 잡 제출
- POST /api/slurm/jobs/<id>/cancel    — 잡 취소
- GET  /api/slurm/nodes               — 노드 목록
- GET  /api/slurm/status              — 클러스터 상태
- GET  /api/storage/data/stats        — 스토리지 통계
- GET  /api/storage/files             — 파일 목록
- POST /api/jobs/submit               — 잡 제출 (통합)
- POST /api/slurm/submit-lsdyna-jobs  — LS-DYNA 잡 제출
- GET  /api/apptainer/images          — 컨테이너 이미지 목록
- POST /api/vnc/sessions              — VNC 세션 생성
- GET  /api/vnc/sessions              — VNC 세션 목록

9. VNC Service Frontend (Port 8002) — 웹 기반 VNC 원격 데스크톱 클라이언트
--------------------------------------------------------------------------------

- React 19 + TypeScript 기반 VNC 세션 관리 UI
- noVNC WebSocket 프록시를 통한 브라우저 내 원격 데스크톱 접속

[기능]
- VNC 세션 생성 (이미지/파티션/GPU/해상도 선택)
- 세션 상태 실시간 모니터링 (Pending → Running → Connected)
- noVNC URL 자동 생성 및 새 탭 접속
- 세션 종료 (Slurm 잡 취소 + SSH 터널 정리)
- 다중 세션 관리

[VNC 실행 흐름]
1. 프론트엔드에서 세션 생성 요청 (파티션/GPU/이미지 선택)
2. 백엔드(5010)가 Slurm sbatch로 VNC 잡 제출
3. 컴퓨트 노드에서 Apptainer 인스턴스 시작 (--nv GPU 패스스루)
4. 컨테이너 내부에서 TigerVNC + 데스크톱(XFCE4/GNOME) 시작
5. websockify로 noVNC WebSocket 프록시 시작
6. 헤드노드에서 SSH 터널 생성 (viz-node:noVNC → localhost:noVNC)
7. Nginx /vncproxy/<port>/ 경유 브라우저 접속

  - useDisplay       — 디스플레이 제어
  - useAppLifecycle  — 앱 생명주기 관리
- APPS
  - BaseApplication — 기본 앱 클래스
  - GEditApp        — 텍스트 에디터 (예제 앱)


13. WebSocket Service (Port 5011) — 실시간 클러스터 모니터링 게이트웨이
--------------------------------------------------------------------------------

- Python WebSocket 서버 (3가지 구현체: 기본/향상/모니터링)

[기능]
- REALTIME_METRICS
  - Slurm 메트릭 주기적 수집 (slurm_data_collector)

- FILE_TRANSFER
  - WebSocket 기반 대용량 파일 전송
- DISK_ALERTS
  - 디스크 사용량 모니터링, 임계값 알림
- PERFORMANCE_MONITORING
  - 시스템 성능 메트릭 수집
- NOTIFICATIONS
  - 이벤트 기반 알림 API
- DATABASE
  - SQLAlchemy 기반 메트릭 영구 저장


14. Nginx Reverse Proxy — 통합 리버스 프록시 및 SSL 종단
--------------------------------------------------------------------------------

- 모든 서비스를 단일 HTTPS(443) 포트로 통합
- HTTP(80) → HTTPS(443) 자동 리다이렉트
- 자체 서명 SSL 인증서 (오프라인 환경)

[라우팅 구성]
- /auth_portal/     → Auth Frontend (4431 정적 파일)
- /auth             → Auth Backend (4430)
- /dashboard/       → Dashboard Frontend (3010 정적 파일)
- /api/             → Dashboard Backend (5010)
- /socket.io/       → Dashboard Backend SocketIO (5010)
- /ws               → WebSocket Service (5011)
- /vnc/             → VNC Frontend (8002 정적 파일)
- /vncproxy/<port>/ → noVNC WebSocket 프록시 (동적 포트)
- /cae/             → CAE Frontend (5173 정적 파일)
- /cae/api          → CAE Backend (5000)
- /cae/vnc/         → CAE VNC 프록시 (5000)
- /app/             → App Frontend (5174 정적 파일)
- /prometheus       → Prometheus (9090)
- /metrics          → Node Exporter (9100)
- /dashboardapi/    → Dashboard Backend (5010, VNC 서비스 호환용)

[WebSocket 지원]
- map $http_upgrade 기반 프로토콜 업그레이드
- Socket.IO, noVNC WebSocket, SSH Terminal 지원
- 타임아웃: VNC 7일, SSH 1시간, 일반 120초

[SSL 설정]
- TLS 1.2/1.3, DH 파라미터 2048bit
- HSTS 활성화 (max-age=63072000)
- 자체 서명 인증서 (/etc/ssl/certs/hpc-selfsigned.crt)


15. Prometheus Monitoring (Port 9090) — 시계열 메트릭 수집/저장
--------------------------------------------------------------------------------

- Prometheus 바이너리 + Node Exporter (9100)
- Grafana 대시보드 연동 (3000)

[수집 메트릭]
- HTTP 요청 수/지연/상태코드
- Slurm 잡 수 (active, pending)
- 노드 상태 (idle, allocated, down)
- 시스템 리소스 (CPU, Memory, Disk, Network)

[알림 규칙]
- NodeDown        — 30초 이상 노드 다운 (critical)
- HighCPU         — CPU 90% 이상 5분 (warning)
- HighDisk        — 디스크 80% 이상 1분 (warning)
- GaleraNodeDown  — DB 노드 10초 이상 다운 (critical)
- VIPFailover     — VIP 페일오버 발생 (info)


================================================================================
시스템 아키텍처 요약
================================================================================

[인증 흐름]
  브라우저 → Auth Frontend(4431) → Auth Backend(4430) → SAML IdP(7000)/OIDC
  → JWT 발급 → 이후 모든 API 요청에 JWT 포함

[데이터 흐름]
  브라우저 → HTTPS(443) → Nginx SSL 종단
    ├→ Frontend 정적 파일 (3010, 4431, 5173, 5174, 8002, 8003)
    ├→ Backend REST API (4430, 5000, 5001, 5010, 8004)
    ├→ WebSocket (5010 SocketIO, 5011 WS)
    └→ noVNC Proxy (동적 포트)

[기술 스택]
  프론트엔드: React 18/19, TypeScript, Vite, Tailwind, Three.js, Babylon.js
  백엔드:    Flask 3.1, SQLAlchemy, PyJWT, Paramiko, AsyncSSH
  인증:      SAML 2.0, OIDC, JWT (python3-saml, Authlib)
  모니터링:  Prometheus, Node Exporter, Grafana
  데이터베이스: SQLite, Redis
  인프라:    Nginx, Gunicorn, Apptainer, Slurm

[포트 맵 — 전체 서비스]

  4431     Auth Frontend (React 정적 파일, Nginx alias)
