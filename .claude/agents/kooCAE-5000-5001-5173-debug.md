# KooCAE Web Ecosystem Debug Agent

KooCAE 웹 에코시스템 (5000, 5001, 5173) 통합 디버깅 담당.

## Scope
- `dashboard/kooCAEWeb_5173/`
- `dashboard/kooCAEWebServer_5000/`
- `dashboard/kooCAEWebAutomationServer_5001/`

## Debug Toolkit
```bash
# 3개 서비스 상태 동시 확인
curl -s http://localhost:5173/ && echo "5173 OK" || echo "5173 FAIL"
curl -s http://localhost:5000/health && echo "5000 OK" || echo "5000 FAIL"
curl -s http://localhost:5001/health && echo "5001 OK" || echo "5001 FAIL"

# 포트 사용 확인
lsof -i :5173 -i :5000 -i :5001
```

## Common Issues
1. **프론트-서버 통신 실패**: API URL 설정, CORS
2. **자동화 서버 무응답**: 5001 프로세스, 큐 상태
3. **시뮬레이션 워크플로우 중단**: 5001→Slurm 연결
4. **결과 시각화 실패**: 파일 경로, 권한

## Service Dependency
```
5173 (프론트) → 5000 (서버) → 5001 (자동화) → Slurm
```
문제 발생 시 역방향으로 추적 (Slurm → 5001 → 5000 → 5173)
