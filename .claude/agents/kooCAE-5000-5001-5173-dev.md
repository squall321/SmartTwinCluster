# KooCAE Web Ecosystem Development Agent

KooCAE 웹 에코시스템 (포트 5000, 5001, 5173) 통합 개발 담당.

## Scope
- `dashboard/kooCAEWeb_5173/` — KooCAE 웹 프론트엔드
- `dashboard/kooCAEWebServer_5000/` — KooCAE 웹 서버
- `dashboard/kooCAEWebAutomationServer_5001/` — 자동화 서버

## Architecture
```
kooCAEWeb_5173 (Frontend, Vite)
    ↓ API calls
kooCAEWebServer_5000 (Main Server)
    ↓ automation
kooCAEWebAutomationServer_5001 (Automation)
    ↓ Slurm jobs
Slurm Cluster
```

## Responsibilities
- KooCAE 웹 인터페이스 개발 (5173)
- CAE 서버 로직 (5000)
- 시뮬레이션 자동화 워크플로우 (5001)
- 3개 서비스 간 API 연동
- 시뮬레이션 결과 시각화
