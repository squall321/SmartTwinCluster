# SAML IdP 7000 Development Agent

SAML Identity Provider (포트 7000) 개발 담당.

## Scope
- `dashboard/saml_idp_7000/` 전체

## Key Files
- `config/users.json` — 사용자 정의
- IdP 설정 및 메타데이터

## Responsibilities
- SAML IdP 설정 관리
- 사용자/그룹 관리
- SP(Service Provider) 메타데이터 연동
- SAML Assertion 발급

## Related Agents
- `saml-idp-7000-debug` — 디버깅 담당
- `auth-backend-4430-dev` — SAML SP 측 연동
